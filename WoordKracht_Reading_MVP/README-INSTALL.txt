WOORDKRACHT READING MVP - INSTALL

Bu paket mevcut index.html dosyanin tam surumunu icerir ve Reading MVP entegre edilmistir.

1) Mevcut projenin yedegini al.
2) Bu paketteki index.html dosyasini proje kokundeki index.html ile degistir.
3) css/style.css dosyasini mevcut css/style.css yerine koy.
4) js/reading.js dosyasini mevcut js/reading.js yerine koy.
5) assets/images/reading-hero.png dosyasini ayni klasore kopyala.
6) js/app.js mevcut uygulama kodunu tasimiyor; mevcut inline JS korunmustur. Bu dosyayi kullanmak zorunda degilsin.
7) Siteyi local server ile ac ve su akisi test et:
   Cards/Home > Vandaag lezen > Start lezen > metin > 5 soru > sonuc.

Not: index-original-backup.html yukledigin orijinal dosyanin yedegidir.
